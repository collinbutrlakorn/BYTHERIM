Tournament (MTE) logos. Name each file after the event in lowercase letters and
numbers only, as a PNG: Maui Invitational -> mauiinvitational.png.

An event without a file here shows a generated badge with its initials, so nothing
breaks while the logos come in. Square or near-square images with a transparent
background look best; they appear from about 18px (scoreboards) to 46px (dashboard).
